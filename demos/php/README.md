# RESTCaptcha PHP Example

This example integrates RESTCaptcha into a PHP project. 

## Dependencies

+ PHP 8.3+
+ [PHP dotenv](https://github.com/vlucas/phpdotenv)
+ [RESTCaptcha PHP Client](https://github.com/openpotato/restcaptcha-client.php)
+ [Bootstrap 5](https://getbootstrap.com/)

## Getting started

1. Copy this file from '.env.template' to '.env' and change the settings according to your needs. By default, the settings are compatible with the RESTCaptcha Visual Studio project running on the same machine. 

2. Open the project folder in [Visual Studio Code](https://code.visualstudio.com/).

3. Run `composer install` from Terminal to install dependencies.

4. Install [PHP Debug](https://marketplace.visualstudio.com/items?itemName=xdebug.php-debug) for PHP support with [Xdebug](https://xdebug.org/).

5. Launch `PHP Debug`.

6. Start task `Open Browser (Windows)` or `Open Browser (Unix)`.
